【Modの名前】
StreetRacerV3

【Modのバージョン】
v3.0.1

【説明】
このmodでは、スプリントレースとサーキットレースができます。
さらに、ストリートレースをGUIを使用して簡単に作成することができます。
自分の車両を追加しておけば、ストリートレースで追加した車両が使用されます！

【特徴】
・20以上の車両。
・5つ以上のストリートレース。
・簡単に作成できるカスタムレース。
・5台の車両をカスタマイズ。
・ランダムに使用する車両。
・自分のカスタム車両を追加でき、レースに使用されます。

【対応言語】
・英語
・日本語

【メニューキー】
L

【前提条件】
・Script Hook V(前提条件あり)
・ScriptHookVDotNet v3.6.0(前提条件あり)
・LemonUI v2.2.0
・.NET Framework 4.8以上
・Microsoft Visual C++ 再頒布可能ファイル
・GTA5 レガシー 最新版

【注意】
カスタムレースはGTA5のマップ用を前提に作成するために開発されました。
modにより追加されたマップを使ってレースを作成することは推奨していません。
このMODは車両が使用されることを前提に開発されています。
オートバイの使用は自己責任となりますので、ご利用の際はご注意ください。

【導入方法】
[StreetRacerV3.dll]を scriptsフォルダに導入
