# StreetRacerV3

[ModVersion]
v3.0.1

[Description]
This mod allows you to play sprint races and circuit races.
Furthermore, you can easily create street races using the GUI.
If you add your own vehicles, they will be used in the street races!

[Features]
- Over 20 vehicles.
- 5 and more street races.
- Easily create custom races.
- Customize 5 vehicles.
- Randomly select vehicles to use.
- Add your own custom vehicles to use in races.

[Supported Languages]
- English @enoyan
- Japanese @enoyan

[MenuKey]
L

[Requirements]
- Script Hook V(There are requirements to use this)
- ScriptHookVDotNet v3.6.0(There are requirements to use this)
- LemonUI v2.2.0
- .NET Framework 4.8 and higher
- Microsoft Visual C++ Redistributable
- GTA5 Legacy Latest version

[Installation]
Install [StreetRacerV3.dll] the scripts folder

[Caution]
Custom races were developed specifically for use with the GTA5 map.
Creating races using maps added by mods is not recommended.
This mod is developed with the assumption that vehicles will be used.
Use of motorcycles is at your own risk, so please keep this in mind when using them.
